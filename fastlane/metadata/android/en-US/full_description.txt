Seali is an independently maintained Android video and audio downloader based on Seal and yt-dlp.

<b>Alpha status</b>
The latest public Seali APKs are 2.0.0-alpha.5. Current source is 2.0.0-alpha.7 and has not been released. Changes on the main branch are not automatically included in published APKs. See the repository README and status document for version-specific verification limits.

<b>Inherited capabilities</b>
Download video and audio from websites supported by yt-dlp.
Extract audio and embed supported metadata and thumbnails.
Download playlists and embed subtitles.
Use the bundled aria2c external downloader.
Create custom yt-dlp command templates and manage downloads.
Material Design 3 interface with dynamic color support.

Compatibility depends on the website and downloader version. These inherited capabilities are not a claim that every site, device or source revision has been revalidated.
